Recall augmented GS model is Gabrovski-Silva but with sigma, kappa >0.

Key innovations of baseline model relative to augmented GS are
1) Variety effects
2) Endogenous exit

Compared to Coles and Kelishomi, augmented GS allows for 3): delta < tau.

Thus, it makes sense to compare role of 1), 2), and 3) delta < tau for mechanism. Perhaps cleanest way is:

1) Variety effects comparison: compare same IRF to model with generalized CES shutting of variety effects (zeta=0)
2) Endogenous exit: compare same IRF to equivalent model with p_0=0 (re-parameterization of baseline)
3) Delta level: compare same IRF now with s=0 (re-parameterization of baseline such that delta_e=tau. Note this requires calibration step since delta < tau

Key variables in IRF: u, v, theta, e, N_e, delta_e. Which others are key? Data-consistent Y, Q, nu_f, d_f?

Design features:

1) Put related variables in same plot and compare IRFs across different figures.
	a) u, v, theta, e in one subplot
        b) N_e, N in another subplot
        c) Q, K in third subplot
        d) z, labor_prod, w, w_int in fourth subplot

  First row (four subplots can be one model), second subplot can be variant (i.e., no variety effects)

2) Each subplot focuses on same variable across model variants. So, one subplot would be just u, another just vacancies, etc.

Units: standard is to express everything in 100*log deviations. But provided steady state is calibrated consistently under same unemployment and vacancy rate across specifications, we can potentially plot u, v in levels (percentage points instead). And delta_e is much more naturally plotted in levels. Alternatively, we can plot percentage deviations of exiting flow of firms: delta_e*N.
